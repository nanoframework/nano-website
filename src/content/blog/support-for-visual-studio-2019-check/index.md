Last week we’ve published nanoFramework [extension](https://marketplace.visualstudio.com/items?itemName=nanoframework.nanoFramework-VS2019-Extension) for [Visual Studio 2019](https://visualstudio.microsoft.com/). Right on time before the official [launch event](https://visualstudio.microsoft.com/vs2019-launch/) on April 2, 2019. ;)

Being Visual Studio a corner stone in nanoFramework development experience, we wanted to show not only our commitment to our growing community by enabling them to keep up with Visual Studio release schedule, but also our appreciation to the Visual Studio team for providing us such an awesome tool.

With the release of the VS2019 version the [extension for VS2017](https://marketplace.visualstudio.com/items?itemName=vs-publisher-1470366.nanoFrameworkVS2017Extension) will enter in maintenance mode. This means that we won’t be adding any new features to it. Only bug fixes and we'll port also any fundamental changes that are required to keep up with new features that cause breaking changes.

As for the VS2019 extension, lots of good stuff is on the queue. We have plans to improve network configuration dialog, provide target updates right from Visual Studio and support for Unit Test.

Now go watch the [launch event](https://visualstudio.microsoft.com/vs2019-launch/), install nanoFramework [extension](https://marketplace.visualstudio.com/items?itemName=nanoframework.nanoFramework-VS2019-Extension) as soon as you get your VS2019 setup and stay tuned for exciting developments.

Follow us on [Twitter](https://twitter.com/nanoFramework), subscribe our [YouTube channel](https://www.youtube.com/c/nanoframework) and rate the extension on the [marketplace](https://marketplace.visualstudio.com/items?itemName=nanoframework.nanoFramework-VS2019-Extension#review-details). Do send your comments and suggest new features.

To wrap up, the usual punch: feel free to contribute with code, samples or any productive work to help the project and the community.

Have fun with the new VS2019 and nanoFramework!
